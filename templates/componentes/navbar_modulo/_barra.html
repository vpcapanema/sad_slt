{# Macro compartilhado dos menus de bloco. Cada bloco do /restrict/ tem o seu proprio componente nesta pasta, que apenas declara os seus itens e chama este macro. Os links sao renderizados dentro da navbar do cabecalho da pagina, substituindo o menu geral: o primeiro item e o inicio do bloco (/restrict/), seguido pelas paginas do modulo. itens: lista de dicionarios com href - destino do link texto - rotulo exibido modo - opcional; quando presente, o item so fica ativo se o query param "modo" da pagina for igual a este valor #} {% macro barra(rotulo, itens) %} {% set caminho = request.url.path if request is defined else "" %} {% set modo_atual = request.query_params.get("modo") if request is defined and request.query_params is defined else none %} Início do bloco {% for item in itens %} {% set ativo = caminho.endswith(item.href.split("?")[0]) and (item.modo is not defined or item.modo == modo_atual) %} {{ item.texto }} {% endfor %} {% endmacro %}
