# Referências de partida

Seleção inicial pesquisada em 26/09/2026. Consulte as páginas durante cada auditoria e registre a data da consulta; estas referências não substituem a inspeção do produto.

- [W3C — WCAG 2.2](https://www.w3.org/TR/WCAG22/): critérios e níveis normativos. Consulte identificação consistente, contraste, reflow, foco e tamanho de alvo quando aplicáveis. Não apresente cumprimento como certificado a partir de revisão estática.
- [W3C — Understanding WCAG 2.2](https://www.w3.org/WAI/WCAG22/Understanding/): interpretação e exemplos dos critérios, incluindo exceções para conteúdo que exige disposição bidimensional.
- [USWDS — Design tokens](https://designsystem.digital.gov/design-tokens/): decisões visuais reutilizáveis para limitar deriva entre componentes. Usar como referência estrutural, sem copiar a identidade visual americana para o SICARD.
- [USWDS — Components](https://designsystem.digital.gov/components/overview/): componentes e orientações de uso, úteis para distinguir variante intencional de duplicação.
- [MDN — Introduction to the CSS cascade](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Introduction): origem, importância, layers e ordem antes de comparar especificidade.
- [MDN — Specificity](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Specificity): peso dos seletores e alternativas a escaladas de especificidade.
- [MDN — Cascade layers](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@layer): CSS normal sem layer prevalece sobre declarações normais em layers. Qualquer migração precisa considerar o legado e o vendor CSS em conjunto.

Pesquise também a documentação oficial das bibliotecas efetivamente envolvidas quando a proposta atingir seus controles. Cite as fontes junto das recomendações, evitando um apêndice genérico sem relação com o diagnóstico.
