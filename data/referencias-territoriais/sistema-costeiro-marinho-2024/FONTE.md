# Referência nacional costeiro-marinha
Fonte: IBGE, Sistema Costeiro-Marinho / Amazônia Azul 2024.
URL: https://geoftp.ibge.gov.br/informacoes_ambientais/estudos_ambientais/biomas/vetores/SistCostMar_AmAz_2024.zip
Consulta: 2026-10-09. Componentes extraídos sem alteração.
Esta camada NÃO estabelece vinculação estadual de área marítima.
A validação usa o recorte derivado ../abrangencia-marinha-sp.geojson, gerado pelo script scripts/gerar_abrangencia_marinha_sp.py.
Fontes, coordenadas, azimutes, método, hash e limitações estão em ../abrangencia-marinha-sp-fontes.json.
O recorte é uma estimativa operacional fundamentada em fontes oficiais; não constitui demarcação jurídica.
